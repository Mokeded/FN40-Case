# FN40 Case

Fusion 360 case design for the **FN40** mechanical keyboard, the companion case for the [FN40-PCB](https://github.com/Mokeded/FN40-PCB) project.

## Contents

- `FN40.f3z` — Fusion 360 archive containing the full case design (top/bottom case, parametric model, and assembly)

## Getting started

1. Install [Autodesk Fusion 360](https://www.autodesk.com/products/fusion-360/overview) (a free personal-use license is available).
2. In Fusion 360, go to **File → Open** and upload/import `FN40.f3z` to open the project, or use **File → Upload** from the data panel.
